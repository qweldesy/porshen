# Поршень — автосервис в Тольятти

Статический сайт автосервиса «Поршень» (ул. Громовой, 33А, стр. 2, Тольятти).

- Контент: карточка организации на Яндекс Картах — https://yandex.ru/maps/org/porshen/1310676232/
- Стек: HTML, CSS, ванильный JS
- Анимации: Motion (локальная сборка, `js/motion.js`)
- Шрифты: Tektur (заголовки), Inter (текст), системный шрифт для телефонов
- Деплой: GitHub Pages, ветка `main`, корень репозитория

## Локальный просмотр

```bash
python3 -m http.server 8901
```

Открыть http://localhost:8901/

## Структура

```
index.html          — разметка и SEO-данные
css/style.css       — дизайн-система и адаптив
js/main.js          — меню, лайтбокс, появление блоков, бегущая строка
js/motion.js        — Motion 14 (vanilla)
fonts/              — Tektur, Russo One, Inter (woff2)
img/                — фото из альбома организации, карта, OG-изображение
```

Данные, отзывы и фотографии взяты из карточки организации. Прайс в карточке не указан, поэтому стоимость работ на сайте не публикуется.
