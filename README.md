# Поршень — автосервис, Тольятти

Одностраничный сайт автосервиса «Поршень». HTML/CSS/JS без сборки, шрифты и изображения — локально.

- **Адрес:** ул. Громовой, 33А, стр. 2, Тольятти
- **Телефон:** +7 (964) 969-23-19
- **График:** ежедневно 09:00–18:00
- **Рейтинг:** 4,3 · 162 оценки · 49 отзывов (Яндекс Карты)

## Источник контента

Всё содержимое — из карточки организации на Яндекс Картах:
<https://yandex.ru/maps/org/porshen/1310676232/>

- виды работ и особенности — из блока «Особенности»;
- отзывы — реальные, с авторами и датами;
- фотографии — 5 фото из альбома организации;
- прайс-листа в карточке нет, поэтому цены на сайте не публикуются: на странице указано, что стоимость уточняется по телефону.

## Структура

```
index.html
css/style.css
js/main.js          — меню, лайтбокс, Motion (motion.dev)
fonts/              — Tektur + Inter (woff2, кириллица + латиница)
img/                — hero, 4 фото альбома, og, favicon
```

## Шрифты

Заголовки — **Tektur** (кириллица проверена рендером до деплоя), текст — **Inter**.
Телефоны набраны системным шрифтом (`-apple-system, Segoe UI, Roboto`).
Обводок и `-webkit-text-stroke` на заголовках нет.

## Мобильная версия

- у fixed-шапки отключён `backdrop-filter` (иначе она становится контейнером для fixed-потомков);
- панель меню вынесена из шапки в `body`;
- бургер — справа через `margin-left:auto`, слой шапки выше панели (100 против 90);
- номер телефона продублирован в панели меню.
